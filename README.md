# 🌳 Decision Tree Algorithms – Machine Learning Project

## 📌 Overview

This project demonstrates the implementation of **Decision Tree–based Machine Learning algorithms** for classification tasks. It includes model building, dataset handling, and performance evaluation using multiple tree-based techniques.

---

## 🚀 Features

* Implementation of Decision Tree (CART & ID3)
* Ensemble methods:

  * Random Forest
  * Gradient Boosting
  * XGBoost
* Dataset preprocessing
* Model training and evaluation
* Accuracy comparison

---

## 🧠 Algorithms Used

* Decision Tree (Gini Index)
* Decision Tree (Entropy)
* Random Forest
* Gradient Boosting
* XGBoost

---

## 📊 Dataset

The dataset used in this project contains features such as:

* Study Hours
* Attendance
* Internal Marks

Target:

* Placement Prediction (Yes/No)

---

## ⚙️ Tech Stack

* Python
* scikit-learn
* XGBoost
* Pandas
* NumPy
